Magento 2 catalog_category_product table

By Gaurav Harsh, Magento developer · 21 November 2026 · Checked against Magento Open Source and Adobe Commerce 2.4.8

Which products are in which categories, and their position in each.

Key columns

ColumnWhat it means
category_idThe category, linking to catalog_category_entity.entity_id.
product_idThe product's ID (entity_id, on Adobe Commerce too).
positionSort order of the product in that category.

Good to know

  • This table holds only direct assignments. Anchor categories also show products from their subcategories, through the storefront index tables.
  • After changing it directly, reindex, or the storefront won't change.

Example: Products that aren't in any category

Magento Open Source

SELECT e.sku, e.type_id
FROM catalog_product_entity e
LEFT JOIN catalog_category_product c ON c.product_id = e.entity_id
WHERE c.product_id IS NULL
ORDER BY e.sku;

Adobe Commerce

SELECT e.sku, e.type_id
FROM catalog_product_entity e
LEFT JOIN catalog_category_product c ON c.product_id = e.entity_id
WHERE c.product_id IS NULL
  AND e.created_in <= UNIX_TIMESTAMP() AND e.updated_in > UNIX_TIMESTAMP()
ORDER BY e.sku;

Tested on Magento Open Source and Adobe Commerce 2.4.8. Read-only. If your tables have a prefix, add it to each table name.
