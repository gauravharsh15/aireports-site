Magento 2 catalog_product_entity_int table

By Gaurav Harsh, Magento developer · 21 November 2026 · Checked against Magento Open Source and Adobe Commerce 2.4.8

Whole-number product values: status, visibility, tax class, and every dropdown attribute (where the value is the option ID). One row per product, attribute and store view.

Key columns

ColumnWhat it means
attribute_idWhich attribute, linking to eav_attribute.
store_id0 = the default value. Any other store view ID overrides it there.
entity_id (Open Source) / row_id (Adobe Commerce)The product. Adobe Commerce links values to a product version through row_id.
valueThe value. Status: 1 = enabled, 2 = disabled. Visibility: 1 = Not Visible Individually, 2 = Catalog, 3 = Search, 4 = Catalog, Search.

Good to know

  • Always check the store-view row before the default: a product can be disabled in just one store view.
  • For dropdown attributes, the value is an option ID. The label is in eav_attribute_option_value.

Example: Enabled and disabled products (default scope)

Magento Open Source

SELECT v.value AS status, COUNT(*) AS products     -- 1 = enabled, 2 = disabled
FROM catalog_product_entity_int v
JOIN eav_attribute a ON a.attribute_id = v.attribute_id AND a.attribute_code = 'status'
JOIN eav_entity_type t ON t.entity_type_id = a.entity_type_id AND t.entity_type_code = 'catalog_product'
WHERE v.store_id = 0
GROUP BY v.value;

Adobe Commerce

SELECT v.value AS status, COUNT(*) AS products     -- 1 = enabled, 2 = disabled
FROM catalog_product_entity_int v
JOIN catalog_product_entity e ON e.row_id = v.row_id AND e.created_in <= UNIX_TIMESTAMP() AND e.updated_in > UNIX_TIMESTAMP()
JOIN eav_attribute a ON a.attribute_id = v.attribute_id AND a.attribute_code = 'status'
JOIN eav_entity_type t ON t.entity_type_id = a.entity_type_id AND t.entity_type_code = 'catalog_product'
WHERE v.store_id = 0
GROUP BY v.value;

Extra columns on Adobe Commerce

Adobe Commerce has 5 columns here instead of 5. The extra ones come from these Commerce features:

  • Catalog Staging: row_id

On Adobe Commerce, entity_id is replaced by row_id, which points at a product version (catalog_product_entity.row_id).

Foreign keys

  • attribute_id → eav_attribute.attribute_id
  • entity_id → catalog_product_entity.entity_id
  • store_id → store.store_id
  • row_id → catalog_product_entity.row_id Adobe Commerce
