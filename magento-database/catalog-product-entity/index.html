Magento 2 catalog_product_entity table

By Gaurav Harsh, Magento developer · 21 November 2026 · Checked against Magento Open Source and Adobe Commerce 2.4.8

One row per product (per version on Adobe Commerce). It has only a few fixed columns; names, prices and everything else are in attribute value tables.

Key columns

ColumnWhat it means
entity_idThe product ID shown in the admin. Order lines, categories and stock link to it.
skuThe product's SKU.
type_idsimple, configurable, bundle, grouped, virtual, downloadable (and giftcard on Adobe Commerce).
attribute_set_idThe attribute set it uses.
created_at / updated_atWhen it was created and last saved.

Good to know

  • There's no name or price column: those are in catalog_product_entity_varchar and catalog_product_entity_decimal.
  • On Adobe Commerce, each product can have several rows, one per scheduled version, with row_id, created_in and updated_in. Filter to the current version: created_in <= UNIX_TIMESTAMP() AND updated_in > UNIX_TIMESTAMP().

Example: Number of products per type

Magento Open Source

SELECT type_id, COUNT(*) AS products
FROM catalog_product_entity
GROUP BY type_id
ORDER BY products DESC;

Adobe Commerce

SELECT type_id, COUNT(*) AS products
FROM catalog_product_entity e
WHERE e.created_in <= UNIX_TIMESTAMP() AND e.updated_in > UNIX_TIMESTAMP()   -- current version only
GROUP BY type_id
ORDER BY products DESC;

Tested on Magento Open Source and Adobe Commerce 2.4.8. Read-only. If your tables have a prefix, add it to each table name.
