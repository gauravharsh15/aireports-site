Magento 2 cataloginventory_stock_item table

By Gaurav Harsh, Magento developer · 21 November 2026 · Checked against Magento Open Source and Adobe Commerce 2.4.8

Stock settings and quantity per product for the default stock. With Multi-Source Inventory (MSI), Magento keeps it in sync with the default source.

Key columns

ColumnWhat it means
product_idThe product's ID.
stock_id1 = the default stock.
qtyQuantity in stock.
is_in_stock1 = in stock, 0 = out of stock.
manage_stock / use_config_manage_stockWhether stock is tracked, or follows the store setting.
backorders0 = no backorders, 1 = allow below zero, 2 = allow and notify the customer.
min_sale_qty / max_sale_qtySmallest and largest quantity per order.

Good to know

  • Many columns come in pairs with use_config_…: when that flag is 1, the store-wide setting applies, not this row's value.
  • With several sources, the real stock is per source in inventory_source_item, and what can still be sold also subtracts open orders (reservations).

Example: In-stock products with fewer than 5 units

Works on Magento Open Source and Adobe Commerce.

SELECT (SELECT p.sku FROM catalog_product_entity p WHERE p.entity_id = si.product_id LIMIT 1) AS sku,
       si.qty
FROM cataloginventory_stock_item si
WHERE si.stock_id = 1
  AND si.is_in_stock = 1
  AND si.qty < 5
ORDER BY si.qty;

Tested on Magento Open Source and Adobe Commerce 2.4.8. Read-only. If your tables have a prefix, add it to each table name.

Extra columns on Adobe Commerce

Adobe Commerce has 28 columns here instead of 26. The extra ones come from these Commerce features:

  • Scalable Inventory: deferred_stock_update, use_config_deferred_stock_update

Foreign keys

  • product_id → catalog_product_entity.entity_id
  • stock_id → cataloginventory_stock.stock_id
  • product_id → sequence_product.sequence_value Adobe Commerce
