Magento 2 core_config_data table

By Gaurav Harsh, Magento developer · 21 November 2026 · Checked against Magento Open Source and Adobe Commerce 2.4.8

Every setting changed under Stores › Configuration, per scope.

Key columns

ColumnWhat it means
scopedefault, websites or stores.
scope_id0 for default, otherwise the website ID or store view ID.
pathThe setting's path, such as web/secure/base_url or general/locale/timezone.
valueThe saved value. Some are encrypted.
updated_atWhen it was last changed.

Good to know

  • Only changed settings are here. Defaults come from each module's config.xml.
  • Values in app/etc/env.php or app/etc/config.php win over this table and lock the field in the admin.
  • It can hold API keys and passwords. Treat exports with care. AI Reports never reads this table.

Example: One setting across all scopes

Works on Magento Open Source and Adobe Commerce.

SELECT scope, scope_id, path, value, updated_at
FROM core_config_data
WHERE path = 'web/secure/base_url'
ORDER BY scope, scope_id;

Tested on Magento Open Source and Adobe Commerce 2.4.8. Read-only. If your tables have a prefix, add it to each table name.

Why AI Reports blocks this table

Settings can include API keys and passwords, so AI Reports never queries this table and hides it from the AI completely. Read the AI safety checklist.
