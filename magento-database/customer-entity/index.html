Magento 2 customer_entity table

By Gaurav Harsh, Magento developer · 21 November 2026 · Checked against Magento Open Source and Adobe Commerce 2.4.8

One row per registered customer account. Guest shoppers aren't here; their details live only on their orders.

Key columns

ColumnWhat it means
entity_idCustomer ID. Orders link to it in sales_order.customer_id.
emailThe login email.
firstname / lastnameThe customer's name.
group_idCustomer group, linking to customer_group.customer_group_id.
website_idThe website the account belongs to (unless accounts are shared across websites).
store_idThe store view it was created in.
default_billing / default_shippingThe default addresses, linking to customer_address_entity.entity_id.
created_atWhen the account was created, in UTC.

Good to know

  • The table also holds password hashes and reset tokens. Never export it whole.
  • Extra customer attributes are stored in customer_entity_varchar, _int and similar tables.

Example: New customer accounts per month this year, per group

Works on Magento Open Source and Adobe Commerce.

SELECT DATE_FORMAT(c.created_at, '%Y-%m') AS month, g.customer_group_code AS customer_group, COUNT(*) AS customers
FROM customer_entity c
JOIN customer_group g ON g.customer_group_id = c.group_id
WHERE c.created_at >= MAKEDATE(YEAR(NOW()), 1)
GROUP BY month, customer_group
ORDER BY month, customer_group;

Tested on Magento Open Source and Adobe Commerce 2.4.8. Read-only. If your tables have a prefix, add it to each table name.
