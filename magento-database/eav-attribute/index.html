Magento 2 eav_attribute table

By Gaurav Harsh, Magento developer · 21 November 2026 · Checked against Magento Open Source and Adobe Commerce 2.4.8

The definition of every attribute of products, categories, customers and addresses: its code, label, input type and which value table holds its data.

Key columns

ColumnWhat it means
attribute_idAttribute ID, used in all the value tables.
entity_type_idWhat it belongs to, linking to eav_entity_type (catalog_product, catalog_category, customer, customer_address).
attribute_codeThe code, such as name, status or color.
frontend_labelThe default label.
backend_typeWhich value table it uses: int, varchar, decimal, text, datetime, or static (a column on the main table).
frontend_inputThe input type: select, multiselect, text, boolean, price and so on.
is_user_defined1 = created in the admin or by an extension, not by Magento core.

Good to know

  • Product-only settings, such as whether an attribute is used as a filter, are in catalog_eav_attribute.

Example: Your own product attributes (created in the admin or by extensions)

Works on Magento Open Source and Adobe Commerce.

SELECT a.attribute_code, a.frontend_label, a.backend_type, a.frontend_input
FROM eav_attribute a
JOIN eav_entity_type t ON t.entity_type_id = a.entity_type_id AND t.entity_type_code = 'catalog_product'
WHERE a.is_user_defined = 1
ORDER BY a.attribute_code;

Tested on Magento Open Source and Adobe Commerce 2.4.8. Read-only. If your tables have a prefix, add it to each table name.
