Magento 2 quote_item table

By Gaurav Harsh, Magento developer · 21 November 2026 · Checked against Magento Open Source and Adobe Commerce 2.4.8

The products in each cart. Like order items, configurable and bundle products have a parent row plus child rows.

Key columns

ColumnWhat it means
item_idInternal ID of the cart line.
quote_idThe cart, linking to quote.entity_id.
parent_item_idNULL for top-level lines; set on the chosen variant of a configurable product.
product_id / sku / nameThe product in the cart.
qtyQuantity in the cart.
price / row_totalUnit price and line total.

Good to know

  • Count only parent_item_id IS NULL to avoid counting configurable products twice.

Example: Products most often sitting in active carts

Works on Magento Open Source and Adobe Commerce.

SELECT qi.sku, MAX(qi.name) AS name, COUNT(DISTINCT qi.quote_id) AS carts, SUM(qi.qty) AS qty
FROM quote_item qi
JOIN quote q ON q.entity_id = qi.quote_id AND q.is_active = 1
WHERE qi.parent_item_id IS NULL
GROUP BY qi.sku
ORDER BY carts DESC
LIMIT 20;

Tested on Magento Open Source and Adobe Commerce 2.4.8. Read-only. If your tables have a prefix, add it to each table name.

Extra columns on Adobe Commerce

Adobe Commerce has 60 columns here instead of 53. The extra ones come from these Commerce features:

  • Catalog Event: event_id
  • Gift Registry: giftregistry_item_id
  • Gift Wrapping: gw_id, gw_base_price, gw_price, gw_base_tax_amount, gw_tax_amount

Foreign keys

  • parent_item_id → quote_item.item_id
  • quote_id → quote.entity_id
  • store_id → store.store_id
