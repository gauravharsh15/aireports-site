Magento 2 sales_order_address table

By Gaurav Harsh, Magento developer · 21 November 2026 · Checked against Magento Open Source and Adobe Commerce 2.4.8

The billing and shipping address of each order, copied at checkout, so later changes to a customer's address book don't change past orders.

Key columns

ColumnWhat it means
entity_idInternal address ID.
parent_idThe order, linking to sales_order.entity_id.
address_typebilling or shipping.
firstname / lastname / companyThe name on the address.
streetThe street lines, separated by a new line.
city / region / postcodeTown, state or county name, and postcode.
country_idTwo-letter country code, such as GB or US.
customer_address_idThe address book entry it came from, if any.

Good to know

  • Orders with only virtual or downloadable products have a billing address but no shipping address.
  • The order also stores billing_address_id and shipping_address_id, pointing at these rows.

Example: Orders per shipping country, last 30 days

Works on Magento Open Source and Adobe Commerce.

SELECT a.country_id, COUNT(*) AS orders
FROM sales_order o
JOIN sales_order_address a ON a.parent_id = o.entity_id AND a.address_type = 'shipping'
WHERE o.created_at >= NOW() - INTERVAL 30 DAY
GROUP BY a.country_id
ORDER BY orders DESC;

Tested on Magento Open Source and Adobe Commerce 2.4.8. Read-only. If your tables have a prefix, add it to each table name.
