Magento 2 sales_order_payment table

By Gaurav Harsh, Magento developer · 21 November 2026 · Checked against Magento Open Source and Adobe Commerce 2.4.8

The payment of each order: the method used, amounts authorised, paid and refunded, and the gateway's references.

Key columns

ColumnWhat it means
parent_idThe order, linking to sales_order.entity_id.
methodPayment method code, such as checkmo, banktransfer or a gateway's own code.
amount_ordered / amount_paid / amount_refundedAmounts in the order currency; base_ versions are in your base currency.
last_trans_idThe latest transaction ID from the payment gateway.
cc_type / cc_last_4Card type and the last four digits, when the gateway provides them.
additional_informationExtra details from the payment method, stored as JSON.

Good to know

  • Magento doesn't store full card numbers or security codes here.
  • Payment-gateway transactions are in sales_payment_transaction.

Example: Orders per payment method, last 30 days

Works on Magento Open Source and Adobe Commerce.

SELECT p.method, COUNT(*) AS orders, ROUND(SUM(o.base_grand_total), 2) AS revenue
FROM sales_order o
JOIN sales_order_payment p ON p.parent_id = o.entity_id
WHERE o.created_at >= NOW() - INTERVAL 30 DAY
GROUP BY p.method
ORDER BY orders DESC;

Tested on Magento Open Source and Adobe Commerce 2.4.8. Read-only. If your tables have a prefix, add it to each table name.
