Magento 2 url_rewrite table

By Gaurav Harsh, Magento developer · 21 November 2026 · Checked against Magento Open Source and Adobe Commerce 2.4.8

Every search-engine-friendly URL on the storefront and what it points to: products, categories, CMS pages and custom redirects.

Key columns

ColumnWhat it means
entity_typeproduct, category, cms-page or custom.
entity_idThe product, category or page ID.
request_pathThe URL people see, such as men/jackets.html.
target_pathWhere it goes: an internal path such as catalog/product/view/id/42, or another URL for a redirect.
redirect_type0 = no redirect, 301 = permanent, 302 = temporary.
store_idThe store view.
is_autogenerated1 = made by Magento, 0 = added by hand.

Good to know

  • A product without a URL rewrite for a store view can still be reached at its internal path, but not at a friendly URL.

Example: Number of URLs per store view and type

Works on Magento Open Source and Adobe Commerce.

SELECT store_id, entity_type, COUNT(*) AS urls, SUM(redirect_type > 0) AS redirects
FROM url_rewrite
GROUP BY store_id, entity_type
ORDER BY store_id, entity_type;

Tested on Magento Open Source and Adobe Commerce 2.4.8. Read-only. If your tables have a prefix, add it to each table name.
